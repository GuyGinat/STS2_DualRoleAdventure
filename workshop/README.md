# DualRoleAdventure (LocalMultiControl)

DualRoleAdventure 是《杀戮尖塔 2》的本地多控改造 Mod。
它的目标很直接：把原本联机下的多角色控制流程，改造成一台电脑上的稳定本地协作体验。
你可以在本地同时运行 2 到 12 个角色，支持重复选角，并在关键流程中顺畅切换控制角色。
这个 Mod 的重点是控制权路由和状态一致性，而不是只做表面 UI 改动。

### 如何进入本地多控

`多人模式` -> `创建` -> `单人多角色`

打开游戏后，进入 `多人模式`，选择 `创建`，再选择 `单人多角色`，即可开始本地多角色流程。

### 内容包含

- 一台电脑上的本地多角色游玩体验
- 战斗和其他关键场景中的快速切人能力
- 事件、奖励、休息区、地图推进等流程的多角色同步

### 说明

- 本 Mod 为纯代码 Mod（`has_dll=true`、`has_pck=false`）
- 不需要额外素材包
- 如果反馈问题，请尽量附上幕数、场景和准确复现步骤

## English

DualRoleAdventure is a local multi-control overhaul for Slay the Spire 2.
Its goal is simple: adapt online multi-character control flow into a stable single-machine co-op experience.
You can run 2 to 12 characters locally, including duplicate picks, and switch control smoothly during key gameplay phases.
The mod focuses on control routing and state consistency instead of flashy UI-only changes.

### How to enter Local Multi-Control

`Multiplayer` -> `Host` -> `Local Multi-Control`

Open the game, go to `Multiplayer`, choose `Host`, then select `Local Multi-Control` to start a local multi-character run.

### What You Get

- Local multi-character play on one PC
- Fast character switching in combat and other key scenes
- Better sync across events, rewards, rest sites, and map progression


### Notes

- This is a code-only mod (`has_dll=true`, `has_pck=false`)
- No extra asset pack is required
- If you report issues, include the act number, scene, and exact reproduction steps
